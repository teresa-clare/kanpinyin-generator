# 看拼音写词语生成器 📝

一个纯前端的看拼音写词语练习卷生成器，需联网。

## ✨ 功能
- 自动标注拼音（支持多音字，也可手动指定 `词|pīn yīn`）
- 田字格排版，支持 A4 / A3 / B5 / Letter
- 三种词汇排列方式：保持输入顺序 / 允许补位 / 按长度排序
- 支持附古诗默写栏目
- 一键打印 / 保存为 PDF

## 🚀 使用
直接打开在线页面即可：
👉 https://teresa-clare.github.io/kanpinyin-generator/

也可以下载 `index.html` 到本地双击打开。

## 📖 拼音指定语法
| 写法 | 效果 |
|---|---|
| `好吗\|hǎo ma` | 手动指定拼音 |
| `女\|nv3` | `v` 表示 ü，数字表示声调 |
| `工作辛苦\|gong1-zuo4-xin1-ku3` | `-` 连写音节 |
